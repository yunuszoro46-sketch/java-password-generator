# Java Password Generator

A beginner Java project that generates random passwords using
SecureRandom.

## Features

- Generates random passwords
- Uses uppercase and lowercase letters
- Includes numbers
- Includes symbols
- Uses SecureRandom

## Example

Generated password:

`gT7#qP2!xL9@`

## Concepts Practiced

- String
- StringBuilder
- SecureRandom
- for loops
- charAt()
